# 灯光与震动连接

2026-11-01：用户已确认 DFRobot DFR0440 按下表接线，并确认串口单次短震后正常停止。灯带为 5V、60 颗，用户补充型号「w2812b」，本方案按 WS2812B RGB 灯带准备；具体芯片修订版及外壳内灯珠位置尚待确认。灯带未接线，暂无独立 5V 电源和电平转换模块。

当前设备已烧录 0.4.1-bringup（仅在 0.4.0 基础上旋转屏幕 180°），`VIBRATION_ENABLED=true`、`LIGHTS_ENABLED=false`。保留 0.3.3 已验收的 balanced_v4 摇动参数；串口确认 IMU、触摸正常，二维码配置保留。独立短震两次均未产生起卦事件，第二次获用户实物确认；用户随后确认完整流程「短震正常，静置不会再次起卦」。当前接线状态下的震动接入验收通过，保留此固件与参数。打印中转已恢复，等待新事件。

## 先连接震动模块

先拔掉开发板 USB，再按接口标识接线。不要按引出线颜色猜 GPIO，也不要将插头位置当作 GPIO 编号。

| DFR0440 标识 | Waveshare SH1.0 引出端 |
| --- | --- |
| S / Signal | GPIO21 |
| VCC / + | VSYS |
| GND / − | GND |

接完后开发板仍由原来的 USB 供电。此接法适用于本项目的 ESP32-S3-Touch-LCD-1.28 触摸版：官方原理图显示 USB VBUS 经二极管接入 VSYS。DFR0440 是带驱动的完整模块，额定供电 5V、支持 3.3V 控制信号，不是把裸马达直接接 GPIO。找不到 VSYS / GPIO21 标识时，先核对官方引脚图和实物方向，不试插。

控制程序：开始起卦短震约 80ms，进入下卦短震约 80ms，双卦确定短震约 140ms；回看双卦、切换二维码、二维码地址更新不重复震动。震动期间及关闭后 500ms 清空摇动检测，避免自激。保留用户已确认的 balanced_v4 摇动参数。

`Board::VIBRATION_ENABLED` 已在接线确认后启用。串口 `vibrate` 只测试一次短震，不起卦、不调用 AI、不打印。使用串口测试前需暂停占用端口的打印中转，完成后恢复。单次短震、阶段震感和静置不重复起卦均已获用户实物确认；此验收对应当前接线与装配状态。

## 灯带等补齐供电后连接

整条灯带暂不接 VSYS、3V3 或 GPIO 取电。按传统 WS2812 RGB 满白每颗最高约 60mA 估算，60 颗约 3.6A；可准备稳压 **5V / 5A** 电源及匹配接头。实际芯片的额定值需再次核对，软件低亮度限制不代替正确供电。打印机 9V / 12V 电源不能直接接此 5V 灯带。

独立供电不一定要新买电源砖：带明确 5V 输出规格的 USB 手机充电头也可评估使用，另需 USB 转供电端子或适合电流的两线供电线。当前灯效最多同时点亮两组、共 16 颗，且白光亮度为 12/255；可先核对现有 5V / 2A 电源用于此限定灯效联调，不运行 60 颗全白满亮测试。若要给整条全亮留出余量，再选 5V / 5A。充电宝在待机灭灯时可能自动关断，固定演示优先使用充电头。电源及线材规格仍待用户提供，尚未据此接通灯带。

待补材料：适合 WS2812B 的 74AHCT125 电平转换模块（3.3V 输入、5V 输出）；约 330Ω 数据串联电阻；500–1000µF、耐压至少 6.3V 的电容；匹配电源接口和电流的供电线。根据具体模块的接口标注接线，不把通用双向 I2C 转换模块默认当作替代品。

| 信号 / 电源 | 后续接法 |
| --- | --- |
| 灯带 +5V | 独立 5V 电源正极 |
| 灯带 GND | 独立电源负极，同时接 ESP32 GND |
| 灯带 DIN | GPIO18 → 74AHCT125 等 3.3V 到 5V 信号转换 → 约 330Ω 串联电阻 → DIN |
| ESP32 | 保持 USB 供电；独立电源 +5V 不接回开发板 VSYS / USB 5V |

输入端以 **DIN** 和箭头方向为准，不能接 DO。电源入口可并联 500–1000µF、耐压至少 6.3V 的电解电容，注意极性。电源接头和线材需满足整条灯带的电流，不用细杜邦线承担整条灯带电源。

灯光程序复用已安装的开源 Arduino-ESP32 / ESP-IDF RMT 驱动，无新增库。按 24-bit WS2812B RGB 协议准备；未确认供电和接线前，设备上的 `Board::LIGHTS_ENABLED` 保持 `false`。

软件验证：2026-11-01 在忽略目录 `.local/esp32/build/led-enabled-check/` 使用副本启用灯光与震动，完整目标编译/链接通过（程序 1,342,981 bytes，静态 RAM 50,784 bytes）。实际源码的灯光开关仍为关闭，没有烧录此测试构建，也没有完成灯带实物验收。

准备的灯效：待机灭灯；出上卦时依次轮询八组，出下卦时保留上卦并继续轮询；确定后对应两组常亮，上下卦相同则亮同一组。低亮度白光用于首次联调。60 颗暂按 `pixel * 8 / 60` 划为 8/7/8/7/8/7/8/7 颗的八组，逻辑卦序为坤、震、坎、兑、艮、离、巽、乾。这是占位映射，必须按实际粘贴的八卦位置校准后才能声称亮对了卦。
