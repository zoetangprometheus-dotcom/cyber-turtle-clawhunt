# 成本、定价与三分钟展示（简版）

日期：2026-11-01。以下是主控建议的商业验证方案，不是实际采购结算、供应商报价或已验证的购买意愿。不修改运行中的产品、收费或硬件。

## 一句话定位

赛博龟壳是一款把东方文化、实体仪式和 AI 对话结合起来的桌面潮玩：摇一摇，拿到一张纸签，再扫码聊聊自己的问题。首批面向喜欢东方美学、桌面互动和创意赠礼的人；细分与支付意愿仍需验证。

## 成本与定价

| 项目 | 建议口径 |
|---|---|
| 当前样机成本 | 按实际采购单累计：板屏/传感器、打印机与电源、外壳、震动、线材、加工和试错耗材。研发工时单列；已有 Mac 是研发/演示设备，不能说用户买回家也无需电脑。现有采购明细未齐，不报已核实总额。 |
| 未来小批量单台成本目标 | 先以 350 元为目标上限，包含硬件、独立打印所需连接/控制部件、供电、外壳、装配、测试、包装与生产损耗。当前独立打印方案未完成，350 元未获供应商验证，需最终 BOM 和试产核实。 |
| 单次直接消耗预算 | 暂按 0.10–0.30 元做预算，一次定义为一张纸签、一次网页长解读和一次追问；更多追问另计。不是实测账单，不含固定服务器、维护人工、支付/渠道费用。 |
| 首轮销售测试 | 建议试售价 699 元；首批体验价 599 元，限首批且收集反馈。基础扫码和本地历史随产品提供，AI 使用额度需明确，暂不设计会员或无限调用承诺。 |
| 价格底线 | 若最终交付成本明显超过 350 元，先优化结构/BOM，或测试 799 元，不靠假设未来规模来掩盖亏损。699 元减 350 元的 349 元差额仍要覆盖税费、渠道、运输、售后、研发和持续服务，不能称为净利润。 |

先以明确标价的真实试用验证自用和赠礼两种购买意愿；展示中只说拟定价格，不把口头喜欢当成交、预订或市场验证。

### 单次预算的依据与边界

DeepSeek 官方价格页于 2026-11-01 查询：deepseek-flash 高峰未缓存输入 0.30 美元/百万 token，输出 1.20 美元/百万 token；非高峰更低。若一轮累计输入 10,000、输出 3,000 token，模型费约 0.0066 美元；仅为预算换算假设 1 美元=7.2 元，则约 0.048 元。这里不是实时汇率，也不是项目实际 token 统计。

若热敏纸预算 2 元/20 米，每张含走纸 0.20 米，则纸约 0.02 元；同样只是计算假设。合计约 0.068 元后，以 0.10–0.30 元预留直接消耗预算。需用实际纸卷价格、纸长及 API usage/billing 替换假设；失败生成、额外提问会增加成本。

来源：[DeepSeek 官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。硬件成本目标未冒充网上报价。

## 三分钟展示顺序

| 时间 | 动作与内容 | 建议讲法 |
|---|---|---|
| 0:00–0:20 | 拿出龟壳，介绍场景 | 遇事不决，我们有时需要的是一个停下来整理想法的契机。赛博龟壳把这段体验做成了一件可以摇动、可以留下纸签的东方桌面潮玩。 |
| 0:20–1:05 | 现场摇动，展示上卦下卦、震动、出纸 | 摇一摇，设备随机确定本次卦象，AI 将它转成现代语言和一个今天可以尝试的小行动。纸签可以带走、赠送或收藏。拿到纸签后读一句，不朗读全文。 |
| 1:05–1:45 | 扫设备二维码，展示同一卦和更长内容，再演示一个短问题 | 纸上短一点，手机里完整一点。可以带着自己的问题问问这一卦，回答始终围绕同一卦和原签展开。历史与日历可回看。这里的历史只存于当前浏览器。 |
| 1:45–2:10 | 说明为什么值得做成实体 | 摇动、震动、拿到纸张，让 AI 的文字成为可以触摸、可以留存的体验。目标场景是桌面互动和创意赠礼。价值在于器物、仪式、内容与完整体验的组合。 |
| 2:10–2:40 | 用一页讲商业方案 | 首版计划卖设备，目标单台成本 350 元，试售价 699 元。以上是待验证目标；接下来通过小批量试用、采购报价与有价格提示的购买测试来校正。 |
| 2:40–3:00 | 真实进度与收尾 | 当前已接通摇动、AI 纸签、扫码长解读与同卦提问，原型依赖 Mac 中转。下一步完成独立运行并验证稳定性。遇事不决，摇壳问问。 |

时间合计 180 秒。现场 AI 生成时继续讲解，避免等待；只演示一个提问。准备一段完整演示录像及一张真实样张作为故障备份，使用时说明是此前录制，不冒充现场成功。

## 不能讲成已完成的事项

- 灯带尚未连接、未启用；不要演示或承诺现有灯效。
- ESP32 脱离电脑的独立打印、正式稳定托管和长期运行稳定性尚未完成验证。
- 历史为同一浏览器本地保存，没有账号和跨设备云同步。
- 不把随机卦象说成预测准确率，不把 350 元目标、699 元试售价说成量产成本或已获市场验证。
- 当前最新连接联调仅确认 USB 全数据发送，仍待用户反馈这次纸签、扫码和再次摇动；之前已有完整实物验收记录，展示前仍应进行一轮现场检查。
