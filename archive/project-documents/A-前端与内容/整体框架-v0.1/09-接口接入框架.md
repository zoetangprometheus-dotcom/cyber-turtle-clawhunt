# H5 接入 B 后端的框架

## 给后续 Codex
本页为待 A/B 确认的接口契约，未部署。沿用 v3.1 路由，不以本稿修改 B 已有实现。当前 h5/app.js 为纯演示。

## 前端需要的五个操作
| 操作 | v3.1 路由/约定 | 返回/处理 |
|---|---|---|
| 领取 | GET /r/{token}（原规范） | 原规范 GET 有领取副作用；建议 GET 只展示入口，显式 POST claim 领取，防预取误占用；须 B 确认，不能单方改协议 |
| 恢复本次签文 | 待 B 提供会话查询路由 | 返回本卦、不可变基础签、会话到期时间、已有任务与结果 |
| 开始深解 | POST /readings/{id}/deep-reading | body 为 theme；带双方约定幂等键；返回 task_id / status / 已完成结果 |
| 读取结果 | GET /readings/{id}/deep-reading | 明确 theme/task_id 查询方式；前端确认响应归属后再更新 |
| 保存 | 客户端 Canvas | 不发送扫码 token；未来有公开分享链接须另定权限与时效 |

## 成功响应建议
```json
{
  "reading_id": "opaque-reading-id",
  "hexagram": {"hexagram_id": 1, "name_zh": "乾", "upper_trigram": "乾", "lower_trigram": "乾", "lines_bottom_to_top": [1,1,1,1,1,1]},
  "base_reading": {"title": "…", "message": "…", "action": "…"},
  "content_origin": "ai",
  "session_expires_at": "ISO-8601 timestamp",
  "deep_readings": []
}
```
以上是形状示意，省略号和时间占位不是合法业务样例。模型文字对象采用上级 06 schema。`content_origin` 可为 ai / fallback / demo，由服务端填写。前端需响应校验，不把 model 文本作为 HTML 注入。

## 状态映射建议
401 会话到期；403 已领取/无权限；404 无效入口；410 入口已过期/撤销；409 已存在任务；429 请求过频；503 暂不可用。实际 HTTP 码与业务 code 由 B 确认，页面根据明确业务 code 显示，不解析错误字符串。

## 真实接入时必须落实
- 从服务端领取会话，推荐同源 HttpOnly/Secure Cookie；需 B 处理 CSRF、认证、限流、TTL、CORS 和日志脱敏。
- 页面加载恢复记录；生成失败后先查询同一任务再重试；重复点击不得重复生成/收费。
- QR 过期与已领取会话到期分开；新一签撤销旧未领取入口，不改旧已领取记录。
- 每次异步结果比较 reading_id、task_id、theme；离页/切记录撤销请求或忽略过期响应。
- 建议轮询起始 1 秒、逐步退避至 5 秒，具体终止时间由 B 的模型预算确定；前端超时不能宣称服务端任务已取消。
- 模型 Key、设备凭据不进入前端包，链接 token 不持久化至 localStorage。
- 生产版移除演示控制台、固定内容和 demo 文案；未接入前持续标记演示。

## 代码替换点
`generate()` 替换为真实提交/查询；`scenario()` 由入口和会话响应驱动；`data.examples` 换为经过校验的服务端不可变记录。保留纯文字展示、导出排版、主题组件和动画即可，不必重做视觉框架。
