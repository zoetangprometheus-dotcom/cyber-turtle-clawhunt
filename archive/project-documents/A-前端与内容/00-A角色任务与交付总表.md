## 现在可以推进与需要配合的工作
- A 可直接推进：选择内容语气、64 卦资料核对、页面草图、Logo 探索、四主题文案。
- B 需提供：打印有效点宽/DPI与中文渲染方式、屏幕像素和窗口尺寸、API 示例及错误码、会话领取方案、模型输出限制。
- C 需提供：器物外观方向、屏幕窗口/出纸口位置与尺寸、表面符号和灯光布局。
- 三人需确认：比赛截止时间、预算、卦象在设备还是后端确定、主题重复生成与缓存策略。

未取得截止时间，采用交付关口推进，不虚构每日排期。

## 建议推进顺序
1. 先共同审阅「一条基础签 + 同卦四主题」样例，确认声音、长度和信息密度。
2. A/B 锁定数据与接口，同时核对 64 卦数据；A/C 对齐器物与数字视觉。
3. 制作真实宽度纸签及 H5 高保真稿，再实现前端和保存功能。
4. 使用真实后端与真机联调，最后根据实测结果制作 Pitch。
