## 页面结构
扫码入口 → 领取并读取本次签文 → 基础签详情 → 可选主题 → 深解结果 → 保存/分享。
使用一个详情页承载基础签、主题及深解，不引入首页、注册页、底部多栏目导航或历史收藏系统。保存基础签始终可达。

## 页面状态与准确文案
| 状态 | 标题 / 正文 | 操作与行为 |
|---|---|---|
| 正在领取 | 正在打开这张签 | 加载；先验证会话，不显示猜测内容 |
| 基础签 | 这一签，留给今天 | 展示固定卦符、名称、上下卦、title/message/action；按钮“保存基础签” |
| 主题未选 | 想从哪个角度看看 | 四主题单选；深解按钮不可提交；文案“也可以直接保存这张签” |
| 已选主题 | 今日 / 自我、感情、事业 / 学业、友情 | 主按钮“深入解读”；选择本身不调用模型 |
| 正在深解 | 正在展开你的这一签 | 保留基础签与所选主题；锁定重复提交；不写虚假百分比 |
| 深解成功 | 模型返回的标题 | 固定栏目“卦象启发”“对你的启发”“一个小行动”；按钮“保存解读卡”“换个主题” |
| AI 失败 | 这次解读没有完成 | “你的基础签还在，可以稍后重试”；按钮“重试解读”“保存基础签” |
| 网络失败 | 暂时连接不上 | “请检查网络后重试”；保留已加载内容，重试前查询已有任务 |
| 入口过期 | 本次扫码已结束 | “这张纸签仍然有效，网页入口已经关闭”；不跳到最新签文 |
| 已被领取 | 这张签已被领取 | “请在最初领取的浏览器中继续查看”；不展示别人签文 |
| 会话过期 | 本次网页会话已结束 | 不再发起深解；已保存图片不受影响；不要求扫描已失效旧码 |
| 无效链接 | 没有找到这张签 | “请检查是否扫描了设备上本次显示的二维码” |
| 生成图片 | 正在准备图片 | 暂时禁用重复导出；不立即显示“已保存” |
| 导出失败 | 图片暂时没有生成 | “可以重试，或复制签文”；按钮“重新生成”“复制文字” |
| 复制成功 | 签文已复制 | 仅剪贴板 API 确认成功后展示 |
| 复制失败 | 未能自动复制 | 展示可选中文字供手动复制 |
| 图片就绪 | 图片已生成 | 展示图片预览与“长按图片保存”；是否支持下载/系统分享需手机实测 |

系统分享被用户取消不显示报错；浏览器返回分享完成也不等于图片已存入相册。

## 交互约束
- 主题未选时不请求深解。生成期间禁止更换主题或重复提交；完成/失败后恢复。
- “换个主题”展开选择区并保留原结果；新结果按主题归属展示，避免旧请求晚到覆盖新主题。
- 刷新通过 B 的会话恢复同一记录及已完成深解；前端不能依靠 URL 中的 reading_id 自行授权。
- QR 的 180 秒只影响入口，领取后的网页采用独立会话，页面不能在 QR 过期时误关闭。
- 第二人起卦不影响第一人的已领取页面。屏幕上的未领取入口撤销由 B 处理。
- 保存卡只包含用户选择的基础签或该主题深解，不携带扫码 token、Cookie、设备 ID 或调试字段。
- 会话过期后的本地已加载内容能否继续导出由团队确认；首版不依赖本地持久化恢复私人记录。

## 动效与可用性 brief
每个组件定义出现、状态过渡、退出三类表现；同一签文卡在基础与深解之间保持视觉连续。建议 180–300ms 的轻淡入/位移，按钮按压约 0.98 缩放，主题切换用选中底板过渡；数值均待设计实测。

阅读正文保持稳定，避免逐字出现或长时间滚动。加载区占位减少跳动；退出完成后再移除节点。键盘可操作、焦点清楚；状态不能只用颜色区分。遵循系统减少动态效果设置，以即时切换代替位移。设备二维码区保持静态高对比，不应用遮挡扫码的动效。

## 设计稿需交付
基础签、选主题、生成中、深解成功、过期、已领取、生成失败、导出预览各一状态。至少检查 320/390/430 CSS px 宽度与长文案；这些是设计测试尺寸，不是已通过测试。
